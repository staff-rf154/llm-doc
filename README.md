# LLM RAG Assistant

Система вопросов-ответов по документации с векторным поиском (RAG). Работает в Docker Compose с FastAPI, Qdrant, Ollama и поддержкой гибридного поиска, переранжирования и автообучения.

## Требования

- Docker, Docker Compose
- ~6-8 ГБ свободной памяти (для моделей эмбеддингов и Ollama)

## Быстрый старт

1. Клонировать репозиторий
2. Скопировать `.env.example` в `.env` и при необходимости поправить значения
3. Запустить сервисы: `docker compose up -d`
4. Открыть http://localhost:8091 (порт настраивается в `.env` через `APP_PORT`)

Приложение автоматически создаёт администратора из `.env` (или предупреждает), загружает модели эмбеддингов при первом старте. 

## Ключевые параметры

- `APP_PORT=8091` — порт веб-интерфейса
- `LLM_MODEL=qwen2.5:3b-instruct` — модель генерации в Ollama
- `QDRANT_COLLECTION=docs` — коллекция в Qdrant
- `ADMIN_USERNAME`, `ADMIN_PASSWORD` — учётные данные администратора

## Документация

Файлы для индексации размещаются в `data/docs/`. Загрузки через веб-интерфейс попадают в `data/docs/upload/`. Документация поддерживает PDF, DOCX, PPTX, ODT/ODS/ODP, XLSX, EPUB, CSV, JSON, XML, YAML, HTML, Markdown и другие текстовые форматы. Индексация запускается из кабинета администратора.

## Автообучение и сферы деятельности

Система поддерживает несколько сфер деятельности (доменных профилей) с собственными системными инструкциями, настройками и синонимами. Активная сфера определяет приоритет параметров: настройки сферы имеют приоритет над локальными значениями из кабинета.

## Перезапуск и очистка

- `docker compose down` — остановка
- `docker compose up -d --build` — пересборка и запуск
- `docker compose down -v` — остановка с удалением томов Qdrant (очистит индекс)

## Техническая оценка

- Архитектура: микросервисная (FastAPI + Qdrant + Ollama + SQLite). Контейнеризация через Docker Compose.
- Векторизация: sentence-transformers `multilingual-e5-base` (embeddings), поддержка гибридного поиска (dense + BM25) и переранжирования cross-encoder.
- Чанкинг: классический RecursiveCharacterTextSplitter (flat chunks). Parent-Child чанкинг не применяется в текущей версии.
- Хранение: SQLite (пользователи, настройки, запросы, доменные профили), Qdrant (векторный индекс).
- Безопасность: сессии cookie, роли `user/admin/system`, скрытый системный пользователь.
- Масштабируемость: асинхронное индексирование, батчи эмбеддингов, параллельная обработка.
- Поддержка форматов: PDF, DOCX, PPTX, ODT/ODS/ODP, XLSX, EPUB, CSV/TSV, JSON/XML/YAML, HTML, Markdown и др. текстовые.
